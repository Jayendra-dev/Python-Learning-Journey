Practice: Understand the Dictionary
Suppose the dictionary contains:
students = {    "Rahul": 85,    "Priya": 92,    "Amit": 78}



- Keys: Rahul, Priya, Amit
- Values: 85, 92, 78
- Data type of keys: String
- Data type of values: Integer
Important: Python dictionaries store data in key: value pairs. Keys must be unique, but values can be repeated.
